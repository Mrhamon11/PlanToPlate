{% comment %} Deliberately standalone — no extends tag, no static tag, no request-dependent tag. Django's own server_error view renders this with template.render() and no context and no request at all, so no context processor (auth, messages, or anything a future one adds) ever runs for this template — and the whole reason we might be here is that something in the request/response pipeline just failed. A dependency on any of that machinery would risk this page failing too, at the exact moment nothing else is available to show the user anything at all. Styled with an inlined style block for the same reason: no dependency on static file resolution succeeding. {% endcomment %}
